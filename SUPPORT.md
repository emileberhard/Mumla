# Support

Start with the [README](README.md) for setup and building Mumla yourself. The
Mac app is only available as the download at <https://mumla.esmadil.se/>; the
iPhone app comes through TestFlight and the App Store.

Report reproducible bugs and feature requests through
[GitHub Issues](https://github.com/emileberhard/Mumla/issues). Include the app
version, macOS or iOS version, device and the steps that reproduce the
problem. Leave out transcripts, recordings,
screenshots of private content and diagnostics you have not read through.

Send TestFlight, account deletion or other private requests to
[eberhard.emil@gmail.com](mailto:eberhard.emil@gmail.com).

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/emileberhard/Mumla/security/advisories/new)
or the email above, not in a public issue.

See [PRIVACY.md](PRIVACY.md) for data handling and deletion requests.
